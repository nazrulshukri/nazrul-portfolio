# Muhammad Nazrul Portfolio

Portfolio website for Muhammad Nazrul bin Ahmad Shukri, positioned for .NET,
full-stack, MES, manufacturing systems, and Europe relocation opportunities.

## Highlights

- one-page recruiter-friendly portfolio
- resume-backed experience, project, education, and certification content
- downloadable resume PDF from `public/Muhammad-Nazrul-Resume.pdf`
- bespoke Open Graph preview image at `public/og.png`
- responsive layout built with React, TypeScript, vinext, and Tailwind CSS

## Local Development

```bash
npm install
npm run dev
npm run build
npm test
```

Node.js `>=22.13.0` is required.
